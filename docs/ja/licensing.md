# ライセンスの方針

refrain は MIT ライセンスで公開しています。このページには、リポジトリに入れてよいもの、
入れてはいけないもの、その理由を書きます。依存を足す前や、自分で書いていないファイルを足す前に
確認してください。

## 依存は許容型のライセンスだけ

使ってよいライセンス: MIT、Apache-2.0、BSD-2-Clause、BSD-3-Clause、ISC、Zlib、Unicode-3.0。
CI で `cargo deny check` が [`deny.toml`](../../deny.toml) の一覧を使って検査します。

使ってはいけないもの:

- **GPL と AGPL**（どの版も）。プログラム全体に及ぶため
- **LGPL と MPL-2.0** は、`deny.toml` に 1 行足すだけでなく、先に判断が必要です。
  どちらも条件付きで使えます

許可するライセンスを一覧に足すのは方針の変更です。足す commit で理由を説明してください。

## このリポジトリに決して入れないもの

| もの | 理由 |
|---|---|
| **ASIO SDK** | Steinberg の独自ライセンスでは再配布できない。GPLv3 で使うとバイナリが GPL になる。ASIO 対応はビルド時に選べる機能にし、SDK はビルドする人が用意する |
| **VST 2 の SDK**、またはそれを元に作り直したヘッダ | 新しいホストには使えなくなっている。refrain は VST 2 に対応しない |
| **第三者のプラグイン**、サンプル、プリセット、録音 | 再配布する権利が無い。テストにはこのリポジトリで作ったプラグインと音を使う |
| **署名の証明書と認証情報** | 秘密情報。CI の secrets に置く。よくあるファイル形式は `.gitignore` で防いでいる |
| **開発者のマシンのパス** | 個人の情報で、他の人には役に立たない。スクリプトは相対パスか環境変数を使う。ホームディレクトリのパスがあると CI が落ちる |

## プラグインの形式

- **VST3**: SDK は 3.8 から MIT ライセンス。refrain は、その SDK から生成されたバインディングの
  [`vst3`](https://github.com/coupler-rs/vst3-rs) crate（MIT OR Apache-2.0）を使う予定です
- **CLAP**: MIT。refrain は [`clack`](https://github.com/prokopyl/clack)（MIT OR Apache-2.0）を使う予定です
- **Audio Unit**: macOS の一部です

## 商標

コードのライセンスは名前やロゴには及びません。「VST」と「ASIO」は Steinberg の商標です。
ここでは、refrain が何に対応しているかを言うためだけに使っています。VST のロゴや
「VST compatible」のバッジを足すときは、先に Steinberg の最新の利用規定を確認してください。

## コーデック

WAV の読み書きと、FLAC・MP3 の読み込みは問題ありません。**AAC のエンコード**には特許が
まだ残っている可能性があります。エンコーダを同梱せず、OS のもの（Media Foundation か
AudioToolbox）を使ってください。
