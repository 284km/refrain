# ロードマップ

機能は 1 段ずつ足していきます。どの段も、macOS と Windows の両方で音を聞くか確かめるかできる
ものが残るところで終えます。

| # | 段 | 状態 |
|---|---|---|
| 1 | デバイスでサイン波を鳴らし、デバイスを使わずにも書き出す | 済み。デバイスでの動作は macOS で確認。Windows は CI でビルドとテスト |
| 2 | CLAP か VST3 のインストゥルメントを読み込み、MIDI キーボードから鳴らす | 次 |
| 3 | プラグインの画面をウィンドウで開く | |
| 4 | プラグインの状態をプロジェクトと一緒に保存・復元する | |
| 5 | タイムライン上で MIDI クリップを録音・再生する | |
| 6 | エフェクトチェーンとミキサー | |
| 7 | プロジェクトを WAV ファイルに書き出す | |

## 段と並行して進めるもの

- **Windows の低レイテンシ。** `wasapi` crate で WASAPI の排他モードを使う。`cpal` は共有モード
  しか使わないため
- **ASIO はビルド時に選べる機能にする。** ASIO SDK はビルドする人が各自で入手する。
  このリポジトリには入れない
- **Audio Unit（macOS）。** VST3 と CLAP のあとで
- **オーディオスレッドでの確保の検出。** debug ビルドで
- **テスト用のプラグインをこのリポジトリで作る。** 第三者のバイナリ無しで、CI でプラグインの
  ホスト機能を検査できるように
- **リリースの準備。** 第三者ライセンスの一覧の自動生成、macOS の署名と公証、Windows の署名
