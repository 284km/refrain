# ロードマップ

機能は 1 段ずつ足していきます。どの段も、macOS と Windows の両方で音を聞くか確かめるかできる
ものが残るところで終えます。

| # | 段 | 状態 |
|---|---|---|
| 1 | デバイスでサイン波を鳴らし、デバイスを使わずにも書き出す | 済み |
| 2 | CLAP か VST3 のインストゥルメントを読み込み、MIDI キーボードから鳴らす | 済み。macOS のデバイスと仮想 MIDI ポートで確認。実機のキーボードと Windows のデバイスではまだ |
| 2a | サステインペダル、ピッチベンド、その他のコントローラー | 済み。ノートしか受け取らないプラグインには refrain がペダルを弾く |
| 2b | VST3 のインストゥルメント | 済み。テスト用プラグインは CLAP 版とサンプル単位で一致。市販の VST3 インストゥルメントを読み込み、書き出しと macOS のデバイスでの再生ができた |
| 3 | プラグインの画面をウィンドウで開く | 済み。CLAP と VST3。テスト用プラグインの画面は CI の macOS と Windows で開き、市販の VST3 の画面は macOS で開いた |
| 4 | プラグインの状態をプロジェクトと一緒に保存・復元する | 済み。CLAP と VST3。テスト用のプロジェクトの復元と保存し直しを CI の macOS と Windows で確認。市販の VST3 インストゥルメントの状態も macOS で保存・復元できた |
| 5 | タイムライン上で MIDI クリップを録音・再生する | 済み。録音はすでにあるクリップに新しいクリップを重ね、メトロノームが鳴る。クリップの再生が、同じフレーズをイベントとして送った場合とまったく同じ音になることを CI で確認 |
| 6 | エフェクトチェーンとミキサー | 次 |
| 7 | プロジェクトを WAV ファイルに書き出す | |

## 段と並行して進めるもの

- **ノートのタイミング。** MIDI 入力から来たノートを、次のブロックの頭ではなく、弾いたときの
  フレーム位置に置く。録音では、すでに各イベントが届いた瞬間を記録している
- **録音のレイテンシ。** 出力のレイテンシの分だけ、録ったイベントを聞こえた音に揃える。
  カウントイン、タイムラインの途中から始まるクリップ、ループ、テンポの変化も足す
- **Windows の低レイテンシ。** `wasapi` crate で WASAPI の排他モードを使う。`cpal` は共有モード
  しか使わないため
- **ASIO はビルド時に選べる機能にする。** ASIO SDK はビルドする人が各自で入手する。
  このリポジトリには入れない
- **Audio Unit（macOS）。** VST3 と CLAP のあとで
- **オーディオスレッドでの確保の検出。** debug ビルドで
- **プラグインのログをオーディオスレッドから外す。** キューを通して
- **プラグインの一覧づくりを別プロセスで。** 一覧の途中で落ちるプラグインがあっても、refrain が
  一緒に落ちないように
- **リリースの準備。** 第三者ライセンスの一覧の自動生成、macOS の署名と公証、Windows の署名
